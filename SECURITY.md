# Security Policy

## Supported versions

PyDES is developed on `main`. Security fixes are applied to `main` and released in the next tagged version. Older versions are not patched.

| Version | Supported |
| --- | --- |
| `main` | Yes |
| Tagged releases before the latest | No |

## Reporting a vulnerability

**Do not open a public issue for a security problem.**

Report it privately in one of two ways:

1. **GitHub private vulnerability reporting** (preferred): go to the
   **Security** tab of this repository and choose **Report a vulnerability**.
2. **Email**: lwellmeyer@kaist.ac.kr with `PyDES security` in the subject line.

Please include:

- a description of the problem and why you think it is a security issue
- the affected file or class
- the smallest reproduction you can manage, including the commit or version
- the impact you believe it has

Once the issue is confirmed, a fix will be prepared privately. Please give us a chance to ship a fix before disclosing publicly.
